# Звуки клиента

Файлы `*.ogg` взяты без изменений из браузерного клиента Stoat
([stoatchat/for-web](https://github.com/stoatchat/for-web),
`packages/client/scripts/assets_fallback/sounds`, v0.16.3), который
распространяется по лицензии GNU AGPL-3.0. Их проигрывает `options.js`
(звуки из «Настройки → Уведомления»).
